# מעשר: מחשבון מעשרות

מחשבון מעשרות שרץ כולו במכשיר של המשתמש. אין שרת, אין חשבונות, והנתונים לא יוצאים מהמכשיר.

## מה יש בתיקייה

| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה כולה: עיצוב, לוגיקה וגופנים בקובץ אחד |
| `sw.js` | שומר את האפליקציה במכשיר כדי שתעבוד בלי אינטרנט |
| `manifest.webmanifest` | מגדיר שם, צבעים ואייקון להתקנה |
| `icons/` | האייקונים למסך הבית ולמחשב |

## העלאה ל-GitHub Pages (חינם)

1. פתחו חשבון ב-github.com וצרו repository חדש וציבורי, למשל בשם `maaser`.
2. בעמוד ה-repository לחצו Add file ואז Upload files, וגררו פנימה את כל תוכן התיקייה, כולל התיקייה `icons`.
3. לחצו Commit changes.
4. עברו אל Settings, ואז Pages. תחת Source בחרו Deploy from a branch, בחרו את הענף `main` ואת התיקייה `/ (root)`, ולחצו Save.
5. אחרי דקה או שתיים האתר זמין בכתובת `https://שם-המשתמש.github.io/maaser/`. זה הקישור ששולחים למשתמשים.

אפשר להשתמש באותה צורה בכל אחסון סטטי אחר (Netlify, Cloudflare Pages). הדרישה היחידה היא כתובת HTTPS.

## איך המשתמש מתקין

- **אייפון:** פותחים את הקישור ב-Safari, לוחצים על כפתור השיתוף ובוחרים ״הוסף למסך הבית״. חשוב להתקין לפני שמזינים נתונים, כי האחסון של האפליקציה המותקנת נפרד מזה של Safari. המחשבון מציג הנחיה כזאת בכניסה הראשונה.
- **מחשב:** פותחים את הקישור ב-Chrome או ב-Edge. אפשר לעבוד ישר בדפדפן, או ללחוץ על סמל ההתקנה בשורת הכתובת כדי לקבל חלון נפרד.

## עדכון גרסה

1. מעלים את הקבצים המעודכנים ל-repository.
2. משנים את מספר הגרסה בשורה `const VERSION = 'maaser-v1.1.0';` שבקובץ `sw.js`, למשל ל-`maaser-v1.1.1`.

בפתיחה הבאה עם אינטרנט המכשירים יורידו את הגרסה החדשה. הנתונים של המשתמשים נשארים במקומם.

## איך הקופה עובדת

- אחרי כל חישוב אפשר ללחוץ ״הוספה לקופה״, והסכום מצטרף ליתרה המצטברת. אפשר גם להוסיף או להסיר חישוב מהקופה מתוך ההיסטוריה.
- ״רישום תשלום״ מוריד מהקופה את הסכום ששולם, כולו או חלקו, ושומר את התשלום בהיסטוריה. תשלום גדול מהיתרה נרשם כתשלום מראש.
- ״איפוס הקופה״ מחזיר את היתרה לאפס. החישובים והתשלומים נשארים בהיסטוריה.

## איפה הנתונים נשמרים

- הקופה, ההיסטוריה וההגדרות נשמרות ב-IndexedDB של הדפדפן, בכל מכשיר בנפרד.
- מחיקת נתוני הדפדפן, מחיקת האפליקציה ממסך הבית או החלפת מכשיר מוחקות את הנתונים. לכן יש בהגדרות ״שמירת גיבוי״ ו״שחזור מגיבוי״.
- ייצוא PDF ו-Excel נוצר במכשיר עצמו, בלי שירות חיצוני.

## קיצורי מקלדת במחשב

ספרות ופעולות מהמקלדת, Enter לסיכום, Backspace למחיקת ספרה, Esc לניקוי, Ctrl+Enter לחישוב המעשר.
