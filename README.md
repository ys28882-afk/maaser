# מעשר: מחשבון מעשרות

מחשבון מעשרות שעובד במכשיר שלכם. אין שרת ואין חשבונות, והנתונים לא יוצאים מהמכשיר.

**לפתיחת המחשבון:** https://ys28882-afk.github.io/maaser/

## התקנה

- **אייפון:** פתחו את הקישור ב-Safari, לחצו על כפתור השיתוף (ב-iOS 26 קודם על שלוש הנקודות •••, ושם על ״שיתוף״) ובחרו ״הוסף למסך הבית״. מומלץ להתקין לפני שמזינים נתונים, כי האחסון של האפליקציה המותקנת נפרד מזה של Safari. המחשבון מציג הנחיה כזאת בכניסה הראשונה.
- **אנדרואיד:** פתחו את הקישור ב-Chrome, לחצו על שלוש הנקודות ובחרו ״התקנת אפליקציה״ או ״הוספה למסך הבית״.
- **מחשב:** פתחו את הקישור ב-Chrome או ב-Edge. אפשר לעבוד ישר בדפדפן, או ללחוץ על סמל ההתקנה בשורת הכתובת כדי לקבל חלון נפרד.

אחרי ההתקנה המחשבון עובד גם בלי אינטרנט, ומתעדכן לבד כשיש חיבור.

## איך הקופה עובדת

- אחרי כל חישוב אפשר ללחוץ ״הוספה לקופה״, והסכום מצטרף ליתרה המצטברת. אפשר גם להוסיף או להסיר חישוב מהקופה מתוך ההיסטוריה.
- ״רישום תשלום״ מוריד מהקופה את הסכום ששולם, כולו או חלקו, ושומר את התשלום בהיסטוריה. תשלום גדול מהיתרה נרשם כתשלום מראש.
- ״איפוס הקופה״ מחזיר את היתרה לאפס. החישובים והתשלומים נשארים בהיסטוריה.

## איפה הנתונים נשמרים

- הקופה, ההיסטוריה וההגדרות נשמרות רק במכשיר שלכם, בכל מכשיר בנפרד.
- מחיקת נתוני הדפדפן, מחיקת האפליקציה ממסך הבית או החלפת מכשיר מוחקות את הנתונים. לכן כדאי להשתמש מדי פעם ב״שמירת גיבוי״ שבהגדרות, ולהעביר נתונים למכשיר חדש עם ״שחזור מגיבוי״.
- ייצוא ל-PDF ול-Excel נעשה במכשיר עצמו, בלי שירות חיצוני.

## קיצורי מקלדת במחשב

ספרות ופעולות מהמקלדת, Enter לסיכום, Backspace למחיקת ספרה, Esc לניקוי, Ctrl+Enter לחישוב המעשר.
